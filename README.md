## Proyectos destacados

### Magic Queue Watch — plataforma de datos end-to-end
Sistema completo de monitorización para los parques de Disneyland Orlando: ingesta del histórico y de la API en vivo, almacenamiento en series temporales, dashboards con alertas y consulta mediante IA a través de un servidor MCP. Todo reproducible con un solo `docker compose up`.

`Python` `Pandas` `Node-RED` `InfluxDB` `Grafana` `Docker` `MCP`

[Ver repositorio](https://github.com/ai-somorrostro/grupo-amd)

### Gestión de inventario
Aplicación full-stack para la administración de inventario, con modelo de datos, lógica de negocio e interfaz de usuario.

`TypeScript` `Node.js` `SQL`

### TFG — Aplicación Android
Aplicación Android desarrollada en Kotlin como Trabajo de Fin de Grado, con arquitectura por capas, persistencia local y consumo de servicios externos. *(Repositorio privado; demo disponible bajo petición.)*

`Kotlin` `Android` `SQLite`

### Wuolah-Downloader
Userscript para descargar apuntes de Wuolah sin esperas de publicidad, ejecutable directamente desde el navegador con Tampermonkey.

`JavaScript` `Tampermonkey`

[Ver repositorio](https://github.com/ryodan14/Wuolah-Downloader)
